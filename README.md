# Prop Demo V1

A self-contained demo prop-firm competition prototype.

## Included
- Account plan selection
- Demo 100% coupon: `FRIENDS100`
- Virtual account activation
- Trader dashboard
- Simulated terminal
- Buy/Sell demo trades
- P&L/equity calculation
- Automatic daily-loss / max-drawdown / profit-target status
- Trade history

## Run
Open `index.html` in a browser.

This V1 is a front-end prototype. It is not connected to a broker, live market feed, payment gateway, or real-money trading.
